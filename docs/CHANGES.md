# Refactor file inventory

The source tree was migrated from `src/app`, `src/components`, `src/lib`, `src/services`, and `src/proxy.ts` to their root-level equivalents. Generated Prisma output moved to `app/generated/prisma`. This is the resulting source/configuration inventory, including the final viewer integration; generated clients, build output, private backups, and QA captures are excluded. It is not a claim that every listed file was newly authored.

Superseded files removed: the previous content editor, content actions, metadata manager, admin navigation, `lib/admin-content.ts`, `lib/metadata-admin.ts`, and the duplicate `(viewer)/page.tsx`. Their replacements are included below. One-off migration generators were removed after execution.

Private `.env` configuration was updated for administrator bootstrapping and the isolated local test database; no values are included here. Existing unrelated default SVG deletions were preserved. No Git commit or deployment was made by this implementation run.
