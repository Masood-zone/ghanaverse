# Payment network marks

Locally served brand artwork, used only to identify a payment method. Marks belong to their respective owners and were retrieved on 17 October 2026.

- `mtn-momo.svg`: [MTN MoMo mark distributed by DPO Pay](https://dpogroup.com/wp-content/uploads/2026/05/MOMO_MTN.svg).
- `telecel-cash.jpg`: [Telecel Cash mark published by Citi Newsroom](https://citinewsroom.com/wp-content/uploads/2024/05/Telecel-Cash-Logo-750x352.jpg).
- `at-money.webp`: [AT Money mark distributed by DPO Pay](https://dpogroup.com/wp-content/uploads/2025/02/AT-Money-logo.webp).

Hosted checkout filtering follows [Paystack metadata documentation](https://paystack.com/docs/payments/metadata/): `mtn` for MTN, `vod` for Telecel, and `atl` for AT. Branding does not change these provider codes.
